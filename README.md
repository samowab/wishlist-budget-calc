# 스팀 위시리스트 예산 역산기 (Wishlist Budget Calculator)

목표 매출이 아니라 **판매가 × 목표 판매 개수**에서 출발해, 스팀 위시리스트 기반 게임의 마케팅 예산을 거꾸로 산출하는 정적 HTML 시뮬레이터입니다.

## 계산 흐름

목표 판매 개수 → (÷ 누적 총 전환율) 필요 위시리스트 수(전체) → (× (1 − 오가닉 비율)) 필요 위시리스트 수(유상) → (× 채널 블렌디드 CPW) **필요 마케팅 예산**

## 주요 기능

- 캐주얼 인디 / 내러티브 어드벤처 / 로그라이크 / 전략·시뮬레이션 / MMORPG / ARPG 장르 프리셋
- 위시리스트 전환 지표(출시 첫 주 전환율, 누적 총 전환율, 오가닉 비율)와 채널별 CPW·믹스를 반영한 예산 역산
- 계산 과정을 단계별로 그대로 노출하는 "예산 계산 과정" 카드
- 캠페인 기간(출시 전 위시리스트 확보) + 매출 집계 기간(출시 후)에 걸친 누적 매출 vs 누적 지출 시뮬레이션, 손익분기 시점 표시
- CPW·전환율·판매가 변화에 따른 민감도 분석
- 입력값은 브라우저 로컬 스토리지에 저장(뷰어 개인 브라우저에만 저장, 서버 전송 없음)

## 사용 방법

`index.html`을 브라우저로 열거나, GitHub Pages로 배포된 주소로 접속하면 바로 사용할 수 있습니다. 별도 빌드 과정이나 서버가 필요 없는 순수 정적 페이지입니다.

## 주의사항

전환율·CPW·리텐션 등은 일반적인 스팀 프리미엄 게임 마케팅 관행을 기준으로 한 예시 추정치입니다. 실제 프로젝트에 적용하기 전 자체 데이터와 실제 견적으로 반드시 재검증하세요.
